# SeafileDock

一个轻量的 **macOS 桌面云盘小组件**，把 Seafile 资料库直接挂在桌面上，拖拽上传、点按下载，不用反复打开 Seafile 客户端界面。

**核心特点：直连云端 API、按需列目录/上传/下载，完全不做本地同步。** 适合那种几 GB 甚至几十 GB、本地磁盘放不下的资料库。

```
┌──────────────────────────────┐
│ ☁️  tongbu · /               │  ← 菜单栏云朵图标单击显示/隐藏
├──────────────────────────────┤
│ ↩  ..                        │
│ 📁 20260625          12-06   │
│ 📄 band.py      8 KB  12-06  │  ← 双击下载 / 悬停点下载按钮
│ 📄 notes.md     2 KB  12-05  │
├──────────────────────────────┤
│ 114 项 · 云端直连，不占本地空间│
└──────────────────────────────┘
   ↑ 拖文件/文件夹到面板即上传
```

## 功能

- **目录浏览**：进入/返回、搜索、面包屑路径
- **拖拽上传**：把文件或整个文件夹拖到面板即上传到当前目录；文件夹保留原有相对结构，大文件走流式 multipart，不占内存
- **下载**：双击文件或点下载按钮下载单个文件；文件夹可递归下载整棵目录树
- **两种显示模式**（菜单栏右键或设置面板切换）：
  - 悬空浮动：置顶、可任意拖动
  - 固定桌面：位置锁定、不置顶、被其他窗口自然遮住，显示桌面时可见，仍可正常点按
- **四种排序**：按名称/按时间 × 混合排序/文件夹优先；默认名称混合排序
- **菜单栏常驻**：单击显示/隐藏，右键菜单含刷新、模式切换、设置、打开下载目录、退出
- **凭据自动获取**：Token 优先从本机 Seafile 客户端数据库只读读取（客户端重新登录后重启本 App 即生效），也支持用账号密码换取、或手动填写
- **无本地镜像**：所有操作走 Seafile Web API，本地只存配置文件

## 构建

需要 macOS 13+ 和 Xcode Command Line Tools（含 `swiftc`、`iconutil`）。

```bash
git clone <your-repo-url>
cd SeafileDock
chmod +x build.sh
./build.sh
```

脚本会用 `swiftc` 编译源码、组装 `SeafileDock.app`（含图标）、做 ad-hoc 签名，产物在仓库同级目录 `../SeafileDock.app`。

> 说明：源码没有使用 SwiftUI 宏（`@State`），因此只需 Command Line Tools 即可编译，无需完整 Xcode。

## 首次配置

1. 启动 `SeafileDock.app`，菜单栏出现云朵图标
2. 单击云朵 → 右键 → 「设置…」（或菜单里的设置项）
3. 填写：
   - **服务器地址**：如 `https://seafile.example.com`
   - **账号**：登录邮箱
   - **资料库 ID**：在 Seafile 网页端打开目标库，地址栏 `/repo/<这个ID>/` 那段
   - **资料库名称**：仅用于显示
   - **下载目录**：默认 `~/Downloads`
4. Token 二选一：
   - 本机装了 Seafile 桌面客户端且已登录 → 留空「手动 Token」，App 会自动从客户端读取（推荐）
   - 否则在设置里输入账号密码点「登录」换取 Token（密码不保存）
5. 点「保存」，目录即加载

## 用法

- **上传**：从 Finder 拖文件到面板，松开即上传到当前目录
- **下载**：双击文件，或悬停行点下载图标；拖整个文件夹进去会递归下载
- **刷新**：菜单栏右键 → 刷新目录
- **自启**：系统设置 → 通用 → 登录项与扩展 → 把 `SeafileDock.app` 加进去

## 隐私与安全

- 默认配置是**占位符**，不含任何真实账号、服务器或资料库 ID
- Token 只保存在本机 `UserDefaults`，不会上传；也支持完全不落盘（每次从 Seafile 客户端现读）
- 账号密码只在换取 Token 时发送给你的 Seafile 服务器，App 不保存密码
- 所有网络请求直连你配置的 Seafile 服务器，不经过任何第三方

